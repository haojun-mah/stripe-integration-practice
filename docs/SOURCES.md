# Sources and adaptation boundary

Checked November 23, 2026.

1. [Prachub: GeoJSON BikeMap integration](https://prachub.com/interview-questions/render-a-geojson-bike-ride-with-markers-and-alternating-paths-via-a-map-api)

   Public practice material describes reading ride coordinates, posting map parameters to a rendering endpoint, saving a binary image, and adding start/end markers and paths with alternating segment colors. It describes three steps; this pack combines reading and the base request into one first part to match the user's two-part interview context.

2. [1Point3Acres: BikeMap integration exercise](https://www.1point3acres.com/interview/problems/bba4944f-e065-4b5f-91be-f3564b9fd691)

   The public preview identifies repository-based integration work. The complete task is gated, so no claim is made that this pack reproduces its unpublished rules.

3. The user's supplied account: clone a repository, implement two parts locally, use `json` and `requests`, test with two JSON inputs, and discuss production improvements.

The generated code, synthetic 35-point ride, API authentication/error rules, validation requirements, renderer, and tests are original exercise material. This pack has exactly two implementation parts. It does not predict the questions or policies in any future Stripe interview.
